УСТАНОВКА

3 шага — и машинка поехала. Переключай стрелочками:

1

Скачай APK

Нажми кнопку "Скачать APK" выше. Файл сохранится в папку "Загрузки" на телефоне.

2

Разреши установку

Android попросит разрешение на установку из неизвестных источников — нажми "Разрешить". Это нормально: приложение не из Google Play.

3

Подключись к машинке

Открой NEON DRIVE → включи Bluetooth на машинке → нажми "Сканировать" → выбери устройство (HC-05/06 или ESP32) → играй.

ВОПРОСЫ

Почему приложения нет в Google Play? +
Приложение можно установить только с этого сайта. Это бесплатно и без регистрации. Для Google Play нужна публикация через аккаунт разработчика — можно сделать позже.
Мой модуль HC-06 — подключится? +
Да. Приложение поддерживает оба типа Bluetooth: классический SPP (HC-05/HC-06) и BLE (ESP32). Тип определяется автоматически при сканировании.
Как транслировать видео с камеры? +
В настройках приложения укажи адрес камеры. Для ESP32-CAM по умолчанию: http://192.168.4.1:81/stream. Нажми иконку камеры на главном экране — увидишь видео прямо в приложении.
Приложение на Windows — как запустить? +
Сейчас Windows-версия собирается из исходников через Flutter. Готовая сборка появится на этой странице позже — следи за обновлениями.
Это бесплатно? +
Да, полностью бесплатно и без рекламы.
